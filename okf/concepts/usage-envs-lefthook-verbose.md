## `LEFTHOOK_VERBOSE`

Set `LEFTHOOK_VERBOSE=1` or `LEFTHOOK_VERBOSE=true` to enable verbose printing.

#### Example

```bash
LEFTHOOK_VERBOSE=1 lefthook run pre-commit
```
