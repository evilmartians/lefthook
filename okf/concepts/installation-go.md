# Go

The minimum Go version required is 1.27 and you can install

- as global package

```bash
go install github.com/evilmartians/lefthook/v2@v2.1.17
```

- or as a go tool in your project

```bash
go get -tool github.com/evilmartians/lefthook/v2
```
