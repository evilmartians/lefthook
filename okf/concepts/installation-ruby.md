# Ruby

```ruby
# Gemfile

group :development do
  gem "lefthook", require: false
end
```

Or globally

```bash
gem install lefthook
```

**Troubleshooting**

If you see the error `lefthook: command not found` you need to check your $PATH. Also try to restart your terminal.
